# Security

This is a free personal project. It has no bug bounty and pays no rewards. Nobody promises to reply to a report, fix a problem, or release a version.

The software is provided "as is", without warranty of any kind, as [LICENSE.md](LICENSE.md) states. You use it at your own risk.

## Report a vulnerability

Do not report vulnerabilities in public issues or pull requests. Report them privately on GitHub: open the repository's **Security** tab and select **Report a vulnerability**.

Include the commit you tested, the steps to reproduce the problem, and what an attacker can do.
